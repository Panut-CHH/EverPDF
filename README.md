# EverPDF — ดาวน์โหลด

โปรแกรมเปิด / แก้ไข / ลงลายเซ็น PDF รองรับภาษาไทย + OCR ภาษาไทย

## ติดตั้ง

1. ไปที่ [**Releases ล่าสุด**](https://github.com/Panut-CHH/EverPDF/releases/latest)
2. ดาวน์โหลดไฟล์ตามเครื่อง
   - **Windows:** `EverPDF-Setup-x.y.z.exe`
   - **Mac (ชิป M1/M2/M3…):** `EverPDF-x.y.z-arm64.dmg`
   - **Mac (ชิป Intel):** `EverPDF-x.y.z-x64.dmg`
3. Windows อาจขึ้นหน้าจอสีน้ำเงิน "Windows protected your PC" → กด **More info** → **Run anyway**

## อัปเดต

ติดตั้งครั้งเดียวพอ — โปรแกรมตรวจหาเวอร์ชันใหม่และดาวน์โหลดให้เองเบื้องหลัง
เมื่อพร้อมจะขึ้นแถบ "พร้อมติดตั้งแล้ว" มุมขวาล่าง → กด **อัปเดตเลย** (หรือปิดโปรแกรม ระบบจะติดตั้งให้ตอนปิด)
