# ฟอนต์สำหรับข้อความภาษาไทย

pdf-lib ฟอนต์มาตรฐาน (Helvetica) **ไม่รองรับภาษาไทย**
ถ้าต้องการพิมพ์ข้อความไทยลง PDF ให้วางไฟล์ฟอนต์ TTF ไว้ที่นี่ในชื่อ:

    NotoSansThai-Regular.ttf

ดาวน์โหลดได้ฟรีจาก Google Fonts: https://fonts.google.com/noto/specimen/Noto+Sans+Thai

ถ้าไม่มีไฟล์นี้ ระบบจะ fallback ไปใช้ Helvetica (พิมพ์ได้เฉพาะอังกฤษ/ตัวเลข) โดยอัตโนมัติ
